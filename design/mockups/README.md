# 디자인 목업 — 검토용

2026-10-05 사용자가 이미지 생성 제한 해제를 알리고 목업 제작을 요청했다. 게임 코드 구현과 별개인 이미지 시안이다. 최종 화면 승인 전이다.

## 결과

- [여섯 항목 목업 보드](reference-style/design-overview.png): 메인 화면, 로비 화면, 전투 화면, 카드 디자인, 주인공 모델 시트, 카드 사용 이펙트.
- [전투 화면 확대 시안](reference-style/battle-screen.png): 3인 파티, 3적, 손패5장, 에너지, 대상별 예고, 피해 미리보기, 더미 표시.

`reference-style`은 사용자가 지정한 참고 스타일을 따른다는 의미이며, 생성된 화면의 최종 승인을 뜻하지 않는다.

## 기준과 제한

사용자가 제공한 SD 픽셀 캐릭터를 직접 이미지 참조로 사용했다. 큰 눈과 약 2.5등신 비율, 흑백 의상·적색 리본·금색 장식, 긴 검은 머리, 대형 붓, 흑백 먹의 궤적이 기준이다. 원소술사와 신성기사는 같은 SD 표현으로 구분한다.

이미지에 표시된 카드 이름·비용·효과·피해·체력·더미 수량은 시각 예시다. 게임 규칙이나 카드 목록에 적용하지 않았다. 특히 백분율 피해, 먹룡 소환, 이펙트의 큰 피해 숫자를 확정된 시스템으로 해석하지 않는다. 단계별 이펙트 그림은 재생 가능한 애니메이션이 아니다.

한글과 숫자는 이미지 생성 결과이므로 실제 UI에서는 별도 텍스트로 렌더링해야 한다. 스프라이트 프레임 정렬, 투명 배경, 정수 픽셀 배율, 실제 버튼 입력과 손패10장/적5마리의 가독성은 아직 검증하지 않았다. 게임 실행 경로는 없다. PNG를 열어 디자인을 검토한다.

기존 `create_assets.py`와 `assets/`는 사용자가 품질을 거절한 수작업 임시 시안이다. 이번 목업과 게임 에셋에 사용하지 않는다.
