# 새 규칙의 검토안

갱신: 2026-10-05. **기본 시스템 먼저, 강화·소모품·유물은 후속 설계**로 순서를 수정했다. 이전의 강화 비용/확률과 소모품 상세 정책은 철회했으며 승인된 규칙이 아니다. 이번 작업은 문서 초안뿐이다.

이전 게임의 수치는 사용하지 않는다. 아래는 사용자가 판단할 수 있도록 구체화한 **제안**이며 아직 승인된 규칙이나 구현 결과가 아니다. 명시된 기본 에너지3·드로우5·손패10·준비덱10/20·최대강화10 등은 유지한다.

## 1. 먼저 결정할 전투 규칙

| 항목 | 권장안 | 이유·영향 |
| --- | --- | --- |
| 에너지 | 파티 공용3, 직업 자원은 별도 | 어느 동료에게 행동을 배분할지 선택하게 함 |
| 준비 덱 | 편성 직업마다 정확히10장, 공용 정확히20장 | 사용자가 지정한 구성 유지 |
| 중복 편성 | 동일 종류 최대3장, 합동기는 각1장 | 종류 수집과 덱 사본을 구분, 초기 덱 구성 가능 |
| 원정 보상 카드 | 스테이지 덱에 추가, 준비덱 장수 제한은 적용 안 함 | 보상·제거·덱 최적화가 실제 선택이 됨 |
| 쓰러진 소유자 | 해당 카드들을 임시 비활성 구역으로 이동, 부활 시 버린 더미에 복귀 | 죽은 동료의 카드가 계속 손패를 막는 문제 방지; 추가 구역 UI 필요 |
| 공통 카드 시전자 | 살아 있는 동료를 활성 시전자로 선택, 카드마다 시전자 필요 여부 정의 | 힘·특성의 출처가 명확하고 주인공 쓰러짐에도 사용 가능 |
| 합동기 | 요구 동료 모두 편성·생존해야 사용; 조건 미달 사본은 임시 비활성 | 일관된 부활/사망 처리 |
| 직업 자원 | 전투 간 초기화, 턴간 유지, 상한은 카드 설계 후 확정 | 50장 덱에서 같은 턴에만 연계를 강요하지 않음 |
| 선천성 | 입장 시 선천성을 앞에 배치, 첫 기본5장 안에서 우선 드로우 | 선천성 때문에 시작 손패나 드로우 수가 임의 증가하지 않음 |
| 보존 | 턴 종료 시 손패 유지, 다음 턴에도 기본5장 드로우 시도 | 넘치는 카드는 지정대로 버린 더미에 이동 |
| 보호막 | 해당 진영 턴 시작 시 기본 보호막 제거, 보존 특성이 있으면 예외 | 아군과 적의 소유 턴 기준이 명확함 |
| 다단히트 | 타격마다 힘 적용·치명타 판정·피해 해결 | 보호막/반격/사망이 도중에 반영됨 |
| 동시 전멸 | 전원 쓰러짐을 패배로 우선 판정 | 보상과 사망 결과를 명확히 함 |
| 소환 상한 | 남은 슬롯만 소환, 초과분 취소, 예고에 현재 가능 수 표시 | 적5마리 상한 보장 |

이 표가 승인되면 RULES와 ARCHITECTURE에 반영한다. 특히 임시 비활성 구역은 현재 확정된 기본 구역에 추가되는 게임 규칙이다. 몰래 엔진 편의 기능으로 넣지 않는다.

## 2. 계산 순서안

기본 공격은 사용자 기본식으로 계산한다. 직업 자원과 상태의 확장은 `floor((기본피해 + 자원 가산 + 힘) × 약화 × 취약 × 치명타 × 기타 명시 배율)` 후 보호막·체력 순서로 검토한다. 최종 피해는0 이상으로 제한한다. 강화·유물의 개입 단계는 기본 계산이 검증된 후 별도 설계한다.

상태 피해·체력 지불·회복은 이 공식을 공유하지 않는다. 예를 들어 체력 지불은 공격이 아니므로 힘·약화·취약·치명타·보호막을 적용하지 않는 안을 권장한다. 상태별로 틱 시점과 예외를 명시한다.

타격 중 사망자는 즉시 정상 행동 대상에서 제외하고, 피해/처치/사망 트리거를 큐로 해결한다. 마지막 사망의 소환·폭발까지 해결한 경계에서 종료를 검사한다. 치명타 확률·배율과 강화에 따른 개별 카드 성장값은 카드 수치안에서 결정한다.

## 3. 회복·편성·실패안

| 항목 | 권장안 |
| --- | --- |
| 스테이지 입장 | 생존 편성 동료 최대 체력으로 회복 |
| 내부 전투 | 체력 유지, 일반/하드의 쓰러진 동료는 승리 후 최대체력20%로 복귀 |
| 휴식 | 초기에는 회복과 동료 대화; 회복량과 정리 선택은 기본 원정 길이 검토 후 결정, 강화는 후속 |
| 일반 편성 | 로비에서만 변경, 합류는 해당 스테이지 완료 뒤 로비에서 처리 |
| 패배 | 해당 원정 종료, 원정 임시 카드·강화·효과를 잃음; 영구 보유/강화 유지 |
| 재화 손실 | 기본 원정과 보상 경제가 검토된 뒤 수치 결정. 이전50% 정산안은 보류 |
| 카드 수집 | 원정 보상은 우선 임시 사본, 스테이지 클리어 때 획득 종류를 영구 등록 |
| 재도전 완화 | 회복·경로 정보 등 아이템 없이 가능한 방식을 먼저 검토; 상세 정책은 기본 원정 검수 뒤 결정 |
| 하드코어 | 종료 시 쓰러진 동료 영구 사망; 승패 모두 적용. 전투 중 부활 성공자는 생존 |
| 주인공/파티 전멸 | 하드코어 캠페인 종료, 슬롯은 결과 열람·내보내기용으로 보존; 자동 삭제 안 함 |

마지막 세 항목은 플레이 경험에 큰 영향을 주므로 활성화 전 검토가 필요하다. 리엔·세라가 사망한 하드코어에서는 합동기가 사라지고 살아 있는 편성만 사용한다. 스토리상 봉인은 남겨진 기록·도구로 대체하는 분기를 작성해야 한다.

난이도별 적 체력·공격·경제 수치는 아직 제안하지 않았다. 동일 수치로 일반/하드/하드코어 라벨만 나눠 놓은 상태를 모드 구현 완료로 보고하지 않는다.

## 4. 강화 — 설계 보류

이전에 제안했던 비용·성공률·등급 배율·실패 하한 표는 철회한다. 새 표를 이번에 정하지 않는다. 기본 전투·덱 성장·원정 길이·카드 가치·경제가 검토된 뒤 최대+10과 원정+3 제한이라는 최종 목표에 맞춰 설계한다. 미래에 확정된 확률은 UI 표시와 실제 거래가 일치해야 한다.

## 5. 소모품·유물 — 설계 보류

초기 원정과 이벤트는 소모품이나 유물 없이 플레이 가능한 구조로 잡는다. 슬롯 초과·교체·드롭·구매·소비·유물별 트리거/대가·가격·효과는 후속 단계에서 하나씩 설계한다. 최종 목표인 소모품15종/기본3슬롯·유물30종은 삭제하지 않는다.

현재 설계하는 취소/저장 범위는 기본 카드의 미확정 대상 선택, 이벤트 선택의 확정 여부, 연결된 다음 방 선택, 전투/방의 중복 해결 방지다. 아이템 관련 선택을 빈 버튼이나 임시 기본값으로 끼워 넣지 않는다.

## 6. 미정 수치의 처리

초기 캐릭터 체력, 직업 자원 상한, 카드100종의 개별 효과·성장, 적 패턴, 유물·소모품·이벤트 상세, 업적·선물 구성, 난이도 배율, 일일 규칙은 다음 콘텐츠 설계 작업의 대상이다. 이번 문서는 이를 구현했다고 주장하지 않는다.
