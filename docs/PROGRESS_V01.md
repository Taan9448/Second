UI 버튼을 배치한 것과 실제 기능을 구분했다. 첫 버전 화면에는 미작동 대장간/유물/소모품/미래 모드를 넣지 않았다. 15개 진행표 숫자는 장기 목표 표시이며, 플레이 가능한 스테이지는1개다. 3인 연습은 동료 합류 구현을 뜻하지 않는다.

검증 명령과 결과는 HANDOFF의 최신 검증을 확인한다. 세부 초기 규칙은 IMPLEMENTATION_V01에 기록했다. 전체 게임을 완성으로 보고하지 않는다.

## 검증 완료

`npm test`:20개 통과. `npm run build`:통과. `npm run test:browser`:첫 장 완주(3전투 경로), 덱/키보드/취소/드래그, 새로고침과 고정 보상, 본편/연습 분리, 1280×720·1920×1080의10손패/5적 배치, 콘솔 오류 없음. 테스트용 최대 배치 fixture와 일반 본편 플레이 결과를 구분했다. 전체15스테이지 밸런스/플레이 시간은 미검증이다. 현재 주인공/먹룡 프레임과 Canvas 연출은 test:motion으로 검수했으며 적/동료 전체 연속 동작은 미구현이다.

최신 개발 범위는 **1스테이지의 느낌 개선**이며, 나머지 스테이지 확장은 사용자 확인까지 보류한다. 구체적인 연출/저장 경계/검수/한계는 [COMBAT_FEEL](COMBAT_FEEL.md)을 따른다.
