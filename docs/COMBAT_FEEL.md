# 1스테이지 전투 표현 개선 — 2026-10-05

사용자 피드백: 정적인 그림 위에 카드만 사용하는 느낌, 대기/무기 동작과 기술 발사·타격감 부족, 카드 과장 장식. 현재 작업은 **1스테이지의 표현과 플레이 감각 개선**에 집중한다. 2~15스테이지와 추가 아이템은 사용자에게 느낌을 확인받기 전까지 확장하지 않는다. 전체 게임 목표는 삭제하지 않는다.

## 실제 변경

- 연묵: 투명 배경 4열×2행 atlas. 대기 4프레임(호흡/머리카락/눈 감기), 붓 공격 4자세(준비/휘두름/후속/복귀). 원본 일러스트의 이동만으로 공격을 표현하던 방식을 교체했다.
- 1스테이지 적: 투명 배경 3열×2행 atlas. 늑대/추격자/집행관 각각 대기·공격 2자세, 대기 호흡과 공격 이동/복귀. 적의 완전한 연속 프레임 애니메이션은 아직 아니다.
- 먹룡: 투명 2열×2행 비행4프레임 atlas를 Canvas에서 재생하며 시전자에서 적까지 이동시킨다.
- Canvas 기술 레이어: 실제 시전자와 대상의 화면 좌표 사이로 먹 궤적을 발사한다. 먹의 일격, 쌍획, 파묵, 먹룡, 보호막, 집중을 구분하고 기존 연습의 화염/얼음/번개/성광/회복에도 표현을 연결했다. 효과 프레임은 requestAnimationFrame으로 그리고 판정/RNG를 변경하지 않는다.
- 연출 큐: 준비→발사→개별 명중→복귀. 다단 공격과 반격도 각각의 판정 이벤트를 보여 준다. 연출 종료까지 추가 카드/턴 명령을 잠가 겹침을 막는다. 같은 기술을 연속 사용해도 새 동작을 시작한다.
- 피격: 반동, 짧은 밝기 변화, 작은 화면 흔들림, 절단선/파편, 약650ms 피해 숫자. 타격음은 저음+짧은 노이즈, 휘두르기는 주파수가 내려오는 노이즈, 보호막·회복은 다른 톤을 사용한다.
- 카드: 기존 큰 생성 삽화와 금색 중첩 프레임을 제거했다. 작은 SVG 기술 표식, 이름·비용·설명을 중심으로 구성했다. 표식은 큰 삽화의 축소판이 아니다.
- 배경: 전투에서 채도/밝기를 낮춰 인물과 기술이 더 잘 보이게 했다. 무대 위 작은 입자는 독립적으로 움직인다.

## 저장과 판정

전투 엔진은 먼저 판정을 완료하며 사용한 카드·피해·보상을 한 번만 저장한다. `BattleEvent.hpAfter/blockAfter`는 해당 명중 이후의 엔진 결과다. 화면은 이전 전투 스냅샷으로 준비/발사를 보여 주다가 각 명중에서 이 값을 읽어 체력/보호막을 갱신하고 끝에 최종 저장 상태로 합류한다. 렌더러에서 피해식을 재계산하지 않는다. 연출 도중 새로고침하면 이미 확정된 결과로 이어져 카드가 재사용되지 않는다. 이벤트 메타데이터는 저장 스키마에 추가하지 않아 기존 prototype-1 저장은 유지한다.

화면 움직임 설정이나 OS의 reduced motion 설정이 꺼져 있으면 프레임 이동·Canvas·흔들림을 끄고 큐를 짧게 처리한다. 음량은 별도 설정을 따른다.

## 검수 경로

`npm test`, `npm run build`, 빌드 뒤 `npm run test:pages`. dev 서버 실행 중 `npm run test:browser`, `npm run test:motion`.

motion 검수는 실제 엔진으로 테스트 전용 저장을 만든다. 동작 프레임 변화, 기술의 4단계, 비어 있지 않은 Canvas 픽셀, 명중 전 체력 유지, 쌍획/보호막/먹룡, 적 공격, 시전 중 새로고침, 모션 끄기를 확인한다. 영상 녹화는 선택 사항이며 `MOTION_VIDEO=1`과 Playwright용 ffmpeg가 필요하다. 테스트 전용 에너지10/덱은 제품에 넣지 않는다. 실제 게임 에너지3와 카드/적 수치는 변경하지 않았다.

## 아직 남은 것

주인공 공격이 모든 기술별로 고유한 긴 스프라이트 시퀀스를 가진 것은 아니다. 적은 2자세이고 동료는 기존 그림의 동작 표현을 유지한다. 배경은 독립 입자를 제외하면 한 장이다. 정교한 환경 레이어/적 다프레임/기술별 인물 동작/전문 녹음 사운드는 추가 작업이다. 기술 연출의 최종 만족도는 사용자의 실플레이 피드백으로 판단한다. 브라우저 자동 검수로 소리의 청감 품질을 검증했다고 주장하지 않는다.
